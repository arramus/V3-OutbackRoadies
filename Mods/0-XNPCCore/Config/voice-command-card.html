Order wheel hold ;

Hold the radial key (default ;, remappable in modconfig.xml <FormationRadial>) to open the multi-page order wheel. Target: whoever you are looking at, else the last ordered, else the nearest - their name sits in the middle, mouse wheel cycles your hires.

page 0 — follow · stay · guard · jump down · crouch · stance · distance · formation
release the key — orders the targeted companion
click while holding — same order for the whole squad
submenus (chevron + tinted border) — click, or rest the cursor on one for a beat, to open
rest on the centre — back to page 0
